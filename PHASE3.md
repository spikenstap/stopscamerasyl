# Помощник при звонке — фаза 3

Вход: главная → «Помощник при звонке». Пользователь сам включает громкую связь,
читает экран согласия, разрешает микрофон и уведомления, нажимает «Слушать звонок».
Ни входящий звонок, ни запуск приложения сами микрофон не включают.

## Поддержка и приватность

Распознавание использует только SpeechRecognizer.createOnDeviceSpeechRecognizer
(Android 12 / API 31+). Сетевого fallback нет. На API 33+ проверяется установленный
локальный языковой пакет; неизвестная поддержка или отсутствующий пакет останавливают
запуск. На API 31–32 ошибки пакета обрабатываются при запуске. На старых Android
доступна ручная проверка описания.

Работает foreground service типа microphone, постоянное уведомление с остановкой.
Аудиофайлы не создаются. Accessibility, запись телефонной линии, автоматическое
включение громкой связи и завершение звонка не используются.

По умолчанию текст только в памяти, очищается при остановке, ошибке, удалении задачи
или уничтожении сервиса. Сохранение включается отдельно для каждого сеанса: последние
12 000 символов финальных результатов сохраняются локально с AES-GCM и ключом Android
Keystore, backup отключён. Сохраняется только один сеанс, предыдущий заменяется.
Экран позволяет показать/удалить сохранение.

Сервис прекращается после 20 секунд без распознанной речи (в том числе при системном
заглушении микрофона) либо через 30 минут. Это защитные ограничения первой версии:
после паузы может понадобиться новый сеанс. Он не перезапускается после уничтожения
процесса. На уведомления влияет системный режим «Не беспокоить».

При DANGER появляется heads-up уведомление; в открытом приложении — отдельный экран
предупреждения. Из фона Android не принуждается открывать Activity: нажатие уведомления
открывает помощника. USE_FULL_SCREEN_INTENT и SYSTEM_ALERT_WINDOW не запрашиваются.
Фактический heads-up зависит от системных настроек уведомлений.

«Проверить описание с AI» отправляет только написанный пользователем текст,
до 1000 символов, в /v1/analyze с type=phone. Распознанный текст туда не подставляется.
Запросы словарей не содержат аудио/транскриптов.

## Словари и алгоритм

assets/call_keywords/ru.json: восемь категорий из ТЗ, идентификаторы фраз, варианты,
веса 1–5. Звёздочка допускается только в конце слова и означает суффикс букв/цифр,
это не произвольное регулярное выражение. Нормализация: нижний регистр, ё→е,
пунктуация заменяется пробелами, пробелы схлопываются. Учитываются границы слов.

Окно — 60 секунд по монотонным часам. Уникальная фраза учитывается один раз.
Частичная гипотеза заменяет предыдущую гипотезу того же высказывания; повтор
неизменившейся гипотезы не продлевает срок совпадения. Финальный результат фиксируется
один раз. На границе 60 000 мс совпадение исключается.

Пороги первой версии в конфиге словаря: CAUTION ≥ 6, DANGER ≥ 10.
Сочетания otp+(bank_security или authority) и remote_access+(bank_security или
money_transfer) сразу дают DANGER. Это эвристики, не вероятности и не доказательства.
Непосредственное отрицание запроса кода/перевода/установки подавляет такое совпадение.
Одни слова «код», «карта», «банк» не создают предупреждений.

Казахские ключевые фразы не генерировались: kk.json версии 1 имеет пустые категории.
В интерфейсе явно указано отсутствие проверенного словаря, запуск на kk отключён.

## Подписанные обновления

Миграция 0002_keyword_dictionaries создаёт таблицу keyword_dictionaries
(lang, version, envelope, etag, updated_at). Существующие таблицы не меняются.

- GET /v1/keywords?lang=ru&version=1: токен устройства, 30 запросов/минуту;
  200 с JSON {payload, signature}, обе строки base64; 404 если словарь не опубликован.
  payload — байты UTF-8 JSON, signature — Ed25519 именно этих байтов.
- ETag — SHA-256 байтов payload в кавычках. Совпавшие If-None-Match и version
  дают 304 без тела. Версия сама по себе не подтверждает совпадение содержимого.
- POST /v1/admin/keywords: X-Admin-Key, тело — словарь. 201 после публикации,
  409 version_conflict при повторной/старой версии, 422 при неверной структуре,
  503 keywords_not_configured без ключа подписи. Аудит содержит только хэш словаря.
  Обновление версии атомарно, включая конкурирующие обновления.

KEYWORD_SIGNING_PRIVATE_KEY — base64 от 32 байт Ed25519 private key, только в
backend/.env. Публичный ключ закреплён в assets/call_keywords/public_key.txt.
Для этого компьютера пара создана локально. Чужой сервер не сможет подписать обновления
для этого APK. При смене ключа нужна пересборка приложения с соответствующим публичным
ключом; секрет нельзя коммитить. Сохраните серверный секрет в безопасном месте.

Клиент проверяет подпись до разбора JSON, язык, структуру и версию. Старую версию и
изменённое содержимое под тем же номером отклоняет. Точное совпадение текущего словаря
допускается для получения ETag. Проверенный словарь хранится в secure storage;
при ошибке обновления работает предыдущий. Bundled JSON доверяется как часть
подписанного APK. Обновление запускается кнопкой вне сеанса.

Публикация локальных словарей без вывода ключей (HTTP только в доверенной локальной сети):

    cd backend
    python -m app.keywords_cli ../assets/call_keywords/ru.json --url http://192.168.123.34:8000
    python -m app.keywords_cli ../assets/call_keywords/kk.json --url http://192.168.123.34:8000

Для следующего изменения увеличьте version. Перед публикацией наполненного kk нужна
проверка носителя. Не уменьшайте version при восстановлении БД.

## Проверка

Юнит-тесты движка: android/gradlew.bat :app:testDebugUnitTest.
KeywordEngineTest.scenarioSetOfTwenty: 10 опасных и 10 безобидных синтетических
текстовых сценариев; метрики относятся только к этому набору. Дополнительно —
окно, комбинации, ASR-варианты, отрицания, повторения, исправленные частичные
результаты и очистка сеанса.

Flutter: flutter analyze, flutter test. Есть согласие/отмена/отказ разрешения,
выключенное сохранение, предупреждение, остановка, ручное описание, пустой kk,
Ed25519, подмена payload, старые версии, другой ключ/язык, ETag/304.
Backend: ruff check ., ruff format --check ., pytest --cov.

До приёмки на реальных звонках необходимы минимум три физические модели:
входящий/исходящий звонок с громкой связью, ru-пакет, заглушение микрофона, пустое
аудио, фон/блокировка экрана, heads-up, остановка из уведомления, очистка текста,
сохранение/удаление через Keystore. Эмулятор этого не подтверждает.
Юридическая формулировка согласия требует проверки юристом для целевых стран.

Первичные источники:
[SpeechRecognizer](https://developer.android.com/reference/android/speech/SpeechRecognizer),
[microphone FGS](https://developer.android.com/develop/background-work/services/fgs/restrictions-bg-start),
[полноэкранные уведомления](https://source.android.com/docs/core/permissions/fsi-limits).
