# StopScam 2.3 — интерфейс

Обновление существующего Flutter-приложения, без изменения серверного контракта,
распознавания звонков и правил хранения данных.

## Направление

Спокойный интерфейс для человека, которому нужно быстро проверить подозрительное
сообщение. На главной один основной вход в проверку; ниже четыре явно подписанных
действия, помощник при звонке, личные номера, компактная статистика и история.
Нет утверждений, что защита включена, пользователь в безопасности или AI безошибочен.
Статистика по-прежнему строится только из реальной локальной истории.

Тёмный зелёный блок с мягким светлым акцентом выделяет основное действие.
Светлая тема использует почти белый фон; тёмная — глубокие зелёные поверхности.
Семантические цвета риска сохранены. Иконки — существующий Material-набор.
Системный шрифт не загружается из сети. Новых runtime-зависимостей нет.

## Общие правила

- Цвета — в app_colors.dart, оформление компонентов — в app_theme.dart.
- Контент ограничен шириной 600 dp, есть SafeArea и вертикальная прокрутка.
- Отступы кратны 4 dp; карточки с радиусом 24 dp, главный блок — 28 dp.
- Основная кнопка минимум 56 dp, остальные действия минимум 48 dp.
- Кнопки используют стандартную обратную связь Material, декоративной анимации нет.
- При увеличенном шрифте плитки главной переходят в один столбец.
- Все новые подписи — в RU/KK ARB; предупреждения и согласия сохранены.
- Поля проверки имеют постоянные названия, подсказки и прежнюю валидацию.
- Ошибки, загрузка, пустая история и тестовый режим остаются явно видимыми.

## Навык

Установлен UI/UX Pro Max из nextlevelbuilder/ui-ux-pro-max-skill:
https://github.com/nextlevelbuilder/ui-ux-pro-max-skill

Использованы рекомендации по Flutter-темам, LayoutBuilder, контрасту, touch targets
и масштабированию текста. Генератор предложил Minimalism & Swiss Style; его
маркетинговая структура не применена. Для mobile utility точного совпадения в базе
не было. Компоновка адаптирована к существующим сценариям StopScam.

## Визуальная проверка

test/design_layout_test.dart проверяет главную и переход к вводу для RU/KK,
светлой/тёмной темы, 360×640, 390×844, 844×390, 800×1024 и текста 200%.
Также измеряет контраст новых текстовых цветовых пар (минимум 4.5:1).
При STOPSCAM_PREVIEW_DIR сохраняет реальные Flutter PNG главной, проверки,
истории и настроек. STOPSCAM_FONT_DIR указывает на локальные Roboto TTF из Flutter
SDK только для отрисовки тестовых снимков. Снимки не используют реальные данные.
Это проверка Flutter layout, не испытание физических устройств или TalkBack.

Результаты: flutter analyze — без замечаний; flutter test — 81 passed, 3 skipped
(live-тесты выключены по умолчанию). 21 новая проверка включает 20 вариантов layout
и проверку контраста. Отдельный запуск с реальными шрифтами сохранил 16 PNG.
